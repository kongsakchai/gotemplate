# Testing

Unit-test conventions for this project.

## Stack

- Primary assertion library: `github.com/stretchr/testify` (`assert`, `require`, `mock`).
- Mocks generated by `mockery` with the `testify` template.
- DB tests use `github.com/DATA-DOG/go-sqlmock`.
- Handler tests use `github.com/labstack/echo/v5` + `echotest` with `echotest.ContextConfig`.
- No `testify/suite` — use plain `t.Run` subtests.

## mockery

- Configured in `.mockery.yml` at repo root; output mocks go to `mock_test.go` next to the interface. Run `make genmock` (or `mockery`).
- Mark interfaces to mock with `//mockery:generate: true`.
- To mock an interface defined in another package, alias it in the consuming package and re-mark it:

```go
//mockery:generate: true
type Servicer = auth.Servicer
```

- Generated helpers return a mock pre-registered with the `*testing.T` (e.g. `newMockStorager(t)`), and expectations use the expressive form `mock.EXPECT().Method(...).Return(...)`.

## Service tests

- Build a service with mocked dependencies (e.g. `NewService(ServiceDeps{Storager: mock, Hasher: mock})`).
- Cover: success path, business-code error path (`serror.As(err)` + compare code/msg), and propagation of dependency errors (`assert.Same(t, dbErr, err)`).

```go
serr, ok := serror.As(err)
assert.True(t, ok)
assert.Equal(t, serr.Code(), ErrTodoNotFound.Code)
assert.Equal(t, serr.Msg(), ErrTodoNotFound.Msg)
```

## Storage / DB tests

- `db, mock, _ := sqlmock.New()` then `sqlxDB := sqlx.NewDb(db, "sqlmock")`.
- Match queries with regex (`mock.ExpectQuery("SELECT COUNT\\(\\*\\) ...")`), assert args with `WithArgs(...)`.
- Cover found / not-found / error for each `(value, bool, error)` return.

## Handler tests (echotest)

- Build a context with `echotest.ContextConfig{JSONBody: ..., PathValues: ...}.ToContextRecorder(t)`.
- Handlers that call `app.Request` need a validator on the recorder context, otherwise validation silently passes: `ctx.Echo().Validator = validator.NewValidator()` (see `app/authapp/authapp_test.go`).
- Inject what the middleware normally sets: `ctx.Set("sub", "user-1")`.
- Construct the app struct directly with mocked dependencies (`&todoApp{sv: mock}`) instead of `NewApp`.
- Assert returned `error` (should usually be `nil` or the business error) and the recorder status/body. Unmarshal body into `app.Response` to check `success`.
- Test `handleError` directly for code→HTTP mapping.

## Command

- `make test` to run all tests with colorized output; `make testcover`, `make coverage` for coverage.
